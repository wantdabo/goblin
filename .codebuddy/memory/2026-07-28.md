## Restore 后 ProjectorSystem 通知修复

**问题**：Stage.Restore() 后 ProjectorSystem 静默，Component 不更新。
**根因**：Snapshot Clone 时 projectdirtymask 已被 ProjectorSystem 清零；Restore 再 Clone 一次 mask 仍为 0；AddBehavior 时 SeekBehaviorInfo 命中已存在 Info、不触发 MarkProjectableDirty。

**修复**：
- `Stage.cs` Restore() 第 332-338 行：重建 behaviorinfodict 后遍历 info.behaviorinfos，对每个 BehaviorInfo 调用 MarkProjectableDirty（内部 IProjectable.MarkAllDirty()）
