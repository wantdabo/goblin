## 第二轮分析（全量复审 Projection + Render）

对 25 个文件 + ObjectPool + GameplayProxy 做全量复审，发现以下问题：

### 🔴 Bug（P0/P1）
1. `Crop.TrimValues` 未防空 → NRE（ProjectorPacket.values 可为 null，CS8604）
2. `PermissionRule` null behaviorinfotype 作为字典 key → TryGetValue 可能 NRE（CS8620）
3. `ValueSerializer` ulong → (long) 溢出，大值损坏
4. `FrequencyRule.Filter` 帧回滚时 `packet.frame - lastFrame < 0 < interval` → 字段误抑制
5. `FacadeComponent` 缺 `Reset()` override，池化回收残留脏数据 + CS8618
6. `FacadeComponent` SG Clone 疑似失效——auto-property backing field 对 SG 不可见，走基类 MemberwiseClone 共享 List/Dict 引用（待验证 SG 行为）
7. `Mirror.RmvActor` 不归还 Component 到池，泄漏

### 🟡 性能（P2）
8. `Crop.Process` 每帧分配 ObserverPacket + 数组未池化（List 池化了，ToArray 数组没池化）
9. `FrequencyRule.Cleanup` 每次 `new List` 分配
10. `NetworkTransport.Send` 每次 `new List<NetworkPacketData>`
11. `Mirror.Apply` Activator.CreateInstance 反射兜底（应删兜底 fail fast）
12. `FrequencyRule.Filter` 64 位循环内重复 null 检查，应提到循环外

### 🟢 设计/风格（P2）
13. `AOIRule` fail-open（null 位置 → 全通过），需文档或改 fail-closed
14. `PermissionRule` fail-open（未注册 → 全通过），权限系统危险，建议默认 0
15. `ProjectionPipeline.Clone` 注释误导（observers List 是共享引用）
16. `ObserverFactory.CreateRuleChain` 的 `id` 参数未使用；switch 无 default
17. `Mirror.datas` 值类型用 `object` 而非 `Component`，丢类型安全
18. `FacadeComponent : Component, IGBL` 冗余 IGBL
19. `ValueSerializer` 不支持类型静默丢失（无 float/string/bool/GBLDict 支持）
20. 多个集合属性未初始化（CS8618）

### 待办优先级
- P0 立即：#1 TrimValues 防空、#2 PermissionRule null key、#5 FacadeComponent Reset
- P1 本期：#3 ulong 溢出、#4 帧回滚、#6 FacadeComponent Clone 验证、#7 RmvActor 归还池
- P2 后续：#8-#12 性能、#13-#20 设计风格

已写入正式文档：`Docs/DualMode/PROJECTION_RENDER_ANALYSIS_ROUND2.md`（6 章：新增 Bug×7、性能×5、设计×8、交叉引用、优先级、lint 基线）。Bug 23（帧回滚）经 ulong 下溢分析降级为 P3 理论性。
